HyperGL

Interactive Hyperbolic Tiling Renderer

A C++17 / OpenGL experiment for generating and visualizing regular {p,q} tilings

Motivation & Goal

The Problem

OpenGL draws in flat screen space, while the demo world lives in the hyperbolic plane. We need curved-space math, but still have to feed ordinary vertices, indices, and shader uniforms to the GPU.

The Goal

Build the mathematical and rendering foundation for hyperbolic scenes: finite regular {p,q} patches, geodesic mesh generation, projection shaders, and runtime controls for comparing tilings.

The Architecture

A strict separation of concerns allows us to do complex non-Euclidean math without confusing the graphics pipeline.

Math Layer
Hyperboloid model, distance, Lorentz isometries, regular tiling metrics.
→
Tiling Layer
Finite BFS patches, duplicate center merging, tile crossing and rebasing.
→
App & Rendering Layer
GLFW window, OpenGL meshes, Poincare projection shader, built-in overlay.

The Tessellation Challenge

In OpenGL, a line between two vertices is screen-linear. Hyperbolic geodesics are mathematically straight inside the curved space, but they appear curved after projection to the disk.

Dynamic Mesh Rebuilding

Edge Segments

If a tile edge has only its endpoints, projection makes the boundary look too flat. Edge segments sample intermediate points with math::geodesic_lerp.

Radial Bands

Curving only the boundary is not enough. Radial bands tessellate the face from tile center to boundary, so the filled floor follows the projected geometry more closely.

Regular {p,q} Presets

The current build can rebuild the patch and mesh at runtime. Here p is the polygon side count and q is the number of polygons meeting at each corner.

1   {4,6}

Squares, six around each corner.

2   {3,7}

Triangles, seven around each corner.

3   {5,4}

Pentagons, four around each corner.

4   {7,3}

Heptagons, three around each corner.

Roadmap

Navigation

Move from the current projected tiling view toward a real first-person camera. The planned approach is tile-local camera state plus rebasing when crossing tile edges.

Minimap

Add a small disk view of nearby tile centers and edges so it is easier to explain where the camera is inside the generated patch.

Shading

Upgrade from flat tile colors and fog toward clearer depth cues: better palettes, lighting-style gradients, edge emphasis, and distance-based atmosphere.

Scene Detail

Introduce simple landmarks or props after the math and navigation feel stable, so the space has recognizable scale and orientation.

Spherical Geometry

Generalize the geometry layer beyond negative curvature so the same renderer can compare hyperbolic tilings with spherical regular tilings.

Projection Choices

Add explicit projection modes for each geometry, including disk projections for hyperbolic space and a suitable view for spherical patches.
